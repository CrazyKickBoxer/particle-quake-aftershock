## Game data

Particle Quake: Aftershock contains **no Quake game data**. It requires
your own legally obtained copy of Quake (retail via Steam/GOG, or the
official shareware release from id Software) to run. `id1/pak0.pak` and
`pak1.pak` are never included in, generated by, or downloaded by this
project's build or packaging scripts.
